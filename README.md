# Roller Coaster Exploratory Data Analysis

Exploratory Data Analysis of a **1,087 × 56 roller coaster dataset** using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Project Overview

This project focuses on understanding the dataset through **data cleaning, validation, statistical analysis, and visualization**.

## What Was Performed

* Inspected dataset structure, data types, missing values, duplicates, and descriptive statistics.
* Cleaned and prepared relevant features, including date and categorical fields.
* Analyzed feature distributions such as **speed, height, G-force, and introduction year**.
* Examined relationships between numerical features using **correlation analysis, scatter plots, and pair plots**.
* Performed categorical and location-based analysis using **groupby, aggregation, filtering, and sorting**.
* Created visualizations to identify important patterns and relationships in the data.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
